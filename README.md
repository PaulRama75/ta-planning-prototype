# RAMISCOPE TA Planning — Prototype

Clickable prototype of the turnaround planning module: sign in as Admin, Planner or Viewer; dashboard, job register, job page with work steps, crafts and tools (live man-hours), review queue, job details with calculated planning hours, access & support (scaffolding, insulation, valves, welds), one-sheet import/export of jobs with tasks by turnaround or whole site, users and setup. Sample data only; changes stay in the viewer's browser.

Open `index.html` in any browser. No sign-in or install needed.
